# Until Winter｜冬日來信

這是一個可安裝到 iPhone 主畫面的輕量倒數 PWA。

## 功能
- 寒假倒數與可修改目標日期（預設 2027-01-21）
- 每日文學語錄，附繁體中文翻譯與作者／作品
- 每日簽到與連續簽到天數
- 寒假願望清單
- 收藏語錄
- 瀏覽器本機儲存，資料留在你的裝置

## 安裝到 iPhone 主畫面
PWA 必須透過 HTTPS 網址提供服務，不能只把 HTML 存在手機裡就期待 iOS 把它當成完整 App。

1. 將整個資料夾內容部署到支援 HTTPS 的靜態網站服務（例如 GitHub Pages）。
2. 用 iPhone 的 Safari 開啟部署後的網址。
3. 點「分享」→「加入主畫面」→「加入」。
4. 之後從主畫面圖示開啟，即可像 App 一樣使用。

## 注意
- 預設日期只是暫定值，請依學校正式行事曆在 App 的「倒數設定」修改。
- 語錄優先採用公版文學作品或可核對的短句；中文翻譯為本 App 自行翻譯。
- 簽到、收藏與願望清單儲存在目前瀏覽器的本機資料中。清除 Safari 網站資料可能會清掉它們。
